# Tidemark — MoonBit 整数资源配置优化与经营分析库

## 需求与定位

生产与经营计划常需在工时、原料或预算受限时，决定多种产品或项目各取多少整数单位。Tidemark 以有界整数资源优化器为核心：在资源容量和各决策数量上限内，求使总价值最大的可行方案。售价、单位变动成本、期间计划和预算差异分析作为管理会计应用层保留。

项目输入为决策价值、数量上限、每单位资源用量及各资源容量；价值可用贡献额或其他同口径整数评分。与只测算预设销量或固定销售配比不同，`optimizer` 会搜索满足多项资源约束的数量组合。项目不宣称是通用数学规划求解器，也不取代完整生产排程、会计或税务系统。

MoonBit 生态已有通用线性与整数规划求解器 [moonopt 0.4.0](https://mooncakes.io/docs/Freon793/moonopt@0.4.0)，支持 MPS/LP 模型、单纯形与整数分支定界等能力。此类求解器可以表达 Tidemark 当前的容量分配问题；Tidemark 不宣称通用求解器能力或生态唯一性。它的较窄定位是把产品售价、单位变动成本、资源耗用和共享固定费用直接组织为财务管理 API，并返回产品销量、收入、成本、贡献和利润明细。其他相邻项目包括 [Aurum](https://github.com/Lyllyl789/aurum)、[moonmoney](https://github.com/haol-05/moonmoney)、[moonbit-accounting 0.3.0](https://mooncakes.io/docs/mhlagent/moonbit-accounting@0.3.0) 与 [finapp 0.1.2](https://mooncakes.io/docs/bobzhang/finapp@0.1.2/shared)；Tidemark 未声明与这些项目已有集成。该项目的价值在于财务领域的直接建模与结果解释，而非比通用规划求解器覆盖更多模型。

## 算法与限制

`optimizer.optimize` 使用分支限界进行精确有界整数搜索。它根据剩余资源计算每个变量的可行数量上限；再为每种资源计算安全的价值上界（零用量决策按各自数量上限计入，其余决策按最高单位资源价值估算），取最紧上界剪枝。只有搜索完成并证明最优时才返回方案；达到搜索节点上限会返回类型化错误，不返回未证明最优的中间解。输入顺序和搜索顺序确定，结果可复现。

模型最多 32 个决策、16 种资源；每单位价值、资源用量、资源容量和决策数量上限均为 0 至 1,000,000,000；每次求解最多探索 250,000 个节点。目标值和资源约束非负，约束形式为资源总用量不超过容量、各决策量不超过上限。暂不支持最低产量、等式约束、负目标值、决策间依赖或非线性关系；搜索最坏情况下仍可能触及节点上限。

## 三个使用场景

1. **多产品受限产能计划：**工时/原料容量为 12/10。餐品售价/单位变动成本 ¥80/¥48、耗用 2/1，饮品 ¥50/¥30、耗用 1/2，甜点 ¥70/¥25、耗用 3/1；数量上限分别为 5/5/4 件，共享固定成本 ¥30。运行 `moon run cmd/capacity --target js`，优化器选择 3/3/1 件，收入 ¥460、变动成本 ¥259、贡献 ¥201、营业利润 ¥171，两项资源均用满。结果由 `portfolio.optimize_capacity_plan` 实际计算。
2. **预算内项目选择：**预算 ¥100,000 时，项目 A/B/C 分别占用 ¥40,000/¥35,000/¥60,000，估计价值 ¥65,000/¥52,000/¥80,000。独立项目假设下，算法选择 A 和 C，资金用满、总价值 ¥145,000；不表示收益联动或风险预测。可在外部接入示例运行。
3. **经营计划与预算复盘：**`planning` 对齐多期、多产品预算和实际，分别解释销量、售价、单位变动成本和固定成本对利润的影响；有界优化方案可再用本量利 API 复核贡献与目标缺口。

## 可复用 API 与工程交付

- `optimizer`：有界整数资源优化、确定性结果、资源用量明细及搜索预算错误。
- `domain` / `engine`：贡献率、保本、目标利润、利润、安全边际和敏感性分析。
- `portfolio`：整数配比归一化、共享固定费用及固定组合目标；也把产品单位贡献连接到资源优化器，返回可核对的产品销量和利润明细。
- `planning`：多期累计、目标差额、预算实际 ID 对齐及四因素利润桥；桥接顺序是会计分解，不作因果推断。
- `interchange`：版本化 JSON 经营分析接口；优化器目前使用纯类型化 MoonBit API。

所有金额用整数分；优化器中的价值和资源单位由调用方统一口径。纯计算与输入/命令行层分开；外部 MoonBit workspace 示例实际导入全部六个包，CI 工作流覆盖原生与 JS 后端。当前共有 81 项自动化测试；公开仓库使用 Apache-2.0 许可证，历史提交可追踪。

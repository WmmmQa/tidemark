# Tidemark｜MoonBit 可增量重算的整数公式运行时

- **申报人** 韦美秋（WmmmQa）
- **方向** 开发者工具 / 数据处理 · 原创 · Apache-2.0
- **仓库** [WmmmQa/tidemark](https://github.com/WmmmQa/tidemark)

应用将对账公式写死在业务代码里时，改规则就要发版。Tidemark 把输入、命名公式和校验条件放进可审查的文本工作表。调用方可编译一次，多次绑定数据，并在一批修改通过全部校验后取得新快照。

十一月新增独立的 `worksheet` 库。它将表达式编译为栈指令，将名字链接到槽位并按依赖排序。循环依赖会报告环路径。更新沿反向依赖传播，公式值不变便停止向下游传播。所有计算使用有符号 Int64，溢出、除零、非整除和校验失败均带行列号，失败后旧快照仍可读取。库可脱离 CLI 和十月的财务包调用。

**复现** [预算例](../examples/budget-reconcile.worksheet) 的基准利润差为 −119,000 分，调整实际固定成本后为 −109,000 分，公式及校验从首次执行 8 项降到重算 4 项。[表计例](../examples/meter-balance.worksheet) 只改总表会拒绝该批修改。均为合成数据。入口与命令见 [使用说明](worksheet.md)，核心测试在 49 组输入上对比增量与全量结果，另覆盖循环、整数边界和失败后重试。

**边界与交付** 本地已有核心库、CLI、两份样例、可执行 API 文档、外部消费者示例和回归测试。当前语法面向固定整数公式，使用方统一单位并声明业务校验。开发期内计划补充正式发布材料及更多实际工作表样本。

**历史与来源** 沿用十月初审未通过的仓库，十月的整数优化、资源敏感性和经营分析属于历史底座。十一月申报范围是新的公式编译和运行模块。实现使用 AI 辅助，参考项目仅用于生态对照，未引入其源码。对照见 [初审自查](november-review.md)。
